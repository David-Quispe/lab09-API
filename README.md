# Laboratorio 09: consumo de API con Retrofit

Aplicación Android con Jetpack Compose que consulta los posts de
[JSONPlaceholder Mock](https://app.beeceptor.com/virtual-sandbox/json-placeholder)
mediante Retrofit. Incluye lista, detalle y navegación, con estado gestionado
por un `ViewModel`.

## Ejecutar

1. Abrir el proyecto en Android Studio y esperar la sincronización de Gradle.
2. Ejecutar la configuración `app` en un emulador o dispositivo con Internet.
3. En la barra inferior, abrir **Posts** y seleccionar una fila para ver su detalle.

Para comprobar la compilación en Windows:

```powershell
.\gradlew.bat :app:assembleDebug
```
